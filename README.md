# Shift Management System

A full-stack web application for managing convenience-store shift schedules and replacement requests.

## Project status

Milestone 1 — Backend foundation in progress.

## Technology stack

### Frontend

- React
- Vite
- TypeScript

### Backend

- Node.js
- Express
- TypeScript
- Prisma ORM
- PostgreSQL
- Zod

## Current progress

- Client and server project structure created
- Express health endpoint implemented
- PostgreSQL development databases configured
- Initial Prisma schema and migration created
- Initial Store, Manager, and Shift Presets seeded
- Prisma database connection verified
